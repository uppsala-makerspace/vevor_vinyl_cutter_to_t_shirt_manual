
# 0. Check if Inkcut is already installed

In this step of
[this vinyl cutter to T-shirt manual](https://richelbilderbeek.github.io/vevor_vinyl_cutter_to_t_shirt_manual/),
we check if Inkcut is already installed.

On a Linux computer, open a terminal window.

Type

```bash
~/inkcut_venv/bin/inkcut
```

If Inkcut starts then it is installed.
